### THIS IS A REPO FOR EXAM PACKAGES FOR NGN STUDIO, NGN Studio can be downloaded here: https://github.com/adam-paige-vc/NGN-Studio/releases 

## How to Install

1. Click the releases button on the right side of the website and find the exam packages or course you want to download, click the .zip file to download the exam package
2. Open **NGN Studio**
3. Click **Package** → **From ZIP** and select the downloaded file
4. The exams will appear in your library instantly
